QUANTUM ARCHITECTURE

Circuit Method & Complexity

Rigorous formulation of the 4-qubit parameterized quantum ansatz and state vector evolution.

01

RY angle encoding

Feature mapping via AngleEmbedding: each lag value \(x_i \in [0, 1]\) rotates qubit \(i\) around the Y-axis by angle \(\theta_i = \pi \cdot x_i\) from ground state \(|0\rangle\), keeping state vectors initially in the X-Z plane.

02

Entangle

3 layers of StronglyEntanglingLayers parameterized by 36 trainable Euler rotation angles (\(3 \times 4 \times 3\)) with circular CNOT entangling gates generating non-local quantum correlations.

03

Measure

Hermitian observable expectation value \(\langle Z_0 \rangle \in [-1, 1]\) evaluated via PennyLane's diff_method="backprop", inverse transformed to physical Megawatts (MW).

Time Complexity O(E · n · L · N · 2^n)
Space Complexity O(2^n + N · n + n · L)
